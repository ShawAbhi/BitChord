# BitChord Agent Rules

1. **NO UNSOLICITED PUSHES:** NEVER commit and push code to the branch unless explicitly asked by the user.
2. **NO UNSOLICITED BUILDS:** NEVER trigger a build (e.g., `./gradlew assemble...`) or create an APK unless explicitly requested by the user.

Your role is to focus strictly on development and code modifications locally. Save the files, but do not automatically deploy, push, or build the project. Always wait for the user to verify the code and explicitly ask for a build or push.
